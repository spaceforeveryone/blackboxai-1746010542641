# Everyone - Coffee Shop

## Project Overview
Everyone is a modern coffee shop and creative collaboration space designed to blend flavors and ideas. It showcases a variety of drinks and an inviting atmosphere perfect for both work and social gatherings. The website features an enticing menu, a reservation system, customer testimonials, and vibrant visuals to enhance the user experience.

## Installation
To run this project locally, clone the repository and open the `index.html` file in your web browser. Follow these steps:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd <project-directory>
   ```
3. Open `index.html` in your preferred web browser.

## Usage
Upon opening the site, you will see the home page featuring a promotional video and important links. The tabs allow users to navigate between different sections:

- **Home**: General information and promotions.
- **Menu**: A detailed list of available drinks and their prices.
- **Reservasi**: A reservation form for booking a meeting room along with package options.

To reserve a space, fill out the form with the required details and select your package. Click "Kirim Reservasi" to submit.

## Features
- Attractive and responsive design using Tailwind CSS.
- Home page with promotional video and links to the menu and reservation sections.
- Dynamic tab navigation for easy exploration of different site sections.
- Reservation form to book spaces with various package options.
- Testimonials from satisfied customers.

## Dependencies
This project utilizes the following external libraries:
- **Font Awesome**: For icons.
- **Tailwind CSS**: For styling the website.

You can access them via CDN links included in the `index.html` file.
